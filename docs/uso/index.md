# Uso diario

Esta parte es para el **personal bibliotecario**. Explica cada pantalla de
Bildumargi en el orden en que se suelen usar.

| Si quieres… | Ve a |
|---|---|
| Preparar los ficheros | [Exportar los listados de AbsysNet](exportar-absysnet.md) |
| Hacer un análisis, o abrir el último | [Cargar los listados](cargar-listados.md) |
| Ver el estado del fondo | [Diagnóstico](diagnostico.md) y [Secciones](secciones.md) |
| Ver tus series y los tomos que faltan | [Series](series.md) |
| Llevar el análisis en papel | [Informe imprimible](informe.md) |
| Decidir compras | [Sugerencias de compra](sugerencias-compra.md) y [Novedades de DILVE](novedades.md) |
| Ver cómo evoluciona el fondo, y las altas y bajas | [Seguimiento](seguimiento.md) |
| Cambiar los datos de la biblioteca, el idioma, los colores o las secciones | [Configuración](configuracion.md) |

!!! tip "Bildumargi describe y sugiere; no decide"
    Bildumargi no propone retirar ejemplares ni maneja presupuestos. Las
    decisiones sobre la colección corresponden al personal bibliotecario.
