# Instalación y administración

Esta parte es para **jefaturas de servicio** y **personal informático**.
Explica cómo instalar Bildumargi y cómo prepararlo para toda la red.

## Orden recomendado

1. Decide el modo de uso: [Requisitos y modos de uso](requisitos.md).
2. Instala: [en un ordenador](instalar-ordenador.md) o
   [en un servidor Linux](instalar-servidor.md).
3. Rellena el [directorio de bibliotecas](directorio.md). Sin él, Bildumargi
   no reconoce a qué biblioteca pertenecen los listados.
4. Opcional, pero recomendable: conecta el
   [catálogo colectivo de la red](catalogo-red.md) para activar las
   sugerencias de compra.
5. Opcional: solicita y configura [DILVE](dilve.md) para las novedades.
6. Ajusta lo común a toda la red en la [Administración de la red](panel-red.md).
7. Planifica [copias y actualizaciones](copias-actualizaciones.md).

!!! success "Funciona desde el primer momento"
    Sin catálogo de la red ni DILVE, Bildumargi ya analiza la colección
    propia. Esas dos piezas añaden las sugerencias de compra.
