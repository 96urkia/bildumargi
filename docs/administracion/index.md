# Instalación y administración

Esta parte explica cómo instalar Bildumargi y conectarlo con DILVE y con el
catálogo MARC. La puede seguir la propia biblioteca: en Windows basta con
instalarlo como cualquier programa.

## Orden recomendado

1. Decide dónde instalarlo: [Requisitos y modos de uso](requisitos.md).
2. Instala: [en Windows](instalar-windows.md) (lo habitual), [con Python](instalar-ordenador.md)
   o [en un servidor Linux](instalar-servidor.md).
3. Opcional, pero recomendable: solicita y configura [DILVE](dilve.md) para
   las sugerencias de compra, las novedades, las series y el idioma.
4. Opcional: conecta el [catálogo MARC](catalogo-marc.md) para conocer el
   idioma de casi todo el fondo, también de lo antiguo.
5. Planifica [copias y actualizaciones](copias-actualizaciones.md).

!!! success "Funciona desde el primer momento"
    Sin DILVE ni catálogo MARC, Bildumargi ya analiza la colección: Diagnóstico,
    Secciones, Seguimiento e Informe. DILVE añade las sugerencias de compra y
    las series.
